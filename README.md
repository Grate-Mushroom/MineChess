# MineChess — Шахматы с минами

Учебный проект на PyQt5, объединяющий классические шахматы с механикой «Сапёра». Фигуры перемещаются по заминированной доске, а игроки должны учитывать скрытые мины при планировании ходов.

## Техническое задание

Приложение на PyQt с интерфейсом, созданным в Qt Designer. Программа должна включать:

- Не менее двух форм (приветственное окно, игровое окно, диалог настроек)
- Не менее 5 различных виджетов
- Использование стандартных диалогов
- Наличие мультимедиа (изображения фигур)
- Работа с БД (чтение, запись, изменение), не менее двух таблиц
- Обработка нажатий клавиш клавиатуры и мыши
- Возможность сборки в standalone .exe

## Возможности

- Шахматный движок: ходы фигур, шах, мат, пат, рокировка, превращение пешки
- Мины: скрытые мины на доске, взрыв при попадании, цифры-подсказки как в «Сапёре»
- Флажки: правая кнопка мыши — поставить/снять флажок на подозрительную клетку
- Таймер: индивидуальные часы для белых и чёрных, штраф за взрыв
- Сохранение: автосохранение состояния партии в БД при выходе и после каждого хода
- История: таблица ходов с временем, фигурой и координатами
- Сложность: выбор количества мин (Легко / Средне / Сложно)

## Управление

- Enter: Продолжить выбранную партию 
- Delete: Удалить выбранное сохранение
- n: Сохранить текущую игру и открыть диалог новой игры
- k: Сохранить игру и выйти из приложения

## Технологии

- Язык: Python 3.9+
- GUI: PyQt5, Qt Designer
- База данных: SQLite3 (встроен в Python)
- Сборка: PyInstaller
